# ToD Monitoring {#tod_monitoring}

the purpose of this repository is to have one repository that contains any metrics that we want to evaluate from the data/software to use it for different purposes

## Is this repo the repo you are looking for?
If you plan to evaluate a metric and publish the result: yes!
If you plan to enact countermeasures (react to metrics): no!
Else: Look further in the repos that seem to include the functionality you are looking for

## Available Packages
### tod_network_monitoring
Enables monitoring of the mobile network connection used during teleoperation.
###  tod_topic_monitoring
Enables the monitoring of timeouts of used defined nodes.
