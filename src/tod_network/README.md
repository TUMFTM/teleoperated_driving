# tod_network
the purpose of this repository is to have one common repository for the /Operator/Network/... and /Vehicle/Network/... namespaces in the tod code. 
Core functionality of the repo are:
 - to send ros2 topics via udp and tcp
 - to receive ros2 topics via udp and tcp
 - to forward/receive ros2 service calls over the network
 - to stream/receive video streams over the network
 - to stream/receive lidar streams over the network

## Is this repo the repo you are looking for?
If you plan to send anything over the network: yes!
If you plan to preprocess something prior to sending it over the network: no!
Else: Look further in the repos that seem to include the functionality you are looking for
