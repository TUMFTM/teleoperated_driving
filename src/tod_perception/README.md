# tod_perception

Packages enabling the operator to understand the surroundings of the teleoperated vehicle.

the purpose of this repository is to have one common repository for the any perception related data processing (that happens inside the tod bathtube)

- process or augment images
- process or augment lidar data
- process or augment perception data
- process any information that is directly related to the operator/vehicle sensing


# Is this repo the repo you are looking for?

If you plan to resize images or decompres lidar pointclouds: yes!
If you plan project bounding boxes or tiny santas into the image: yes!
If you plan to stream a video or pointcloud: no!
If you plan to visualize an image or want to convert autoware messages to tod_perception messages: no!
Else: Look further in the repos that seem to include the functionality you are looking for (e.g. vehicle bridge)
