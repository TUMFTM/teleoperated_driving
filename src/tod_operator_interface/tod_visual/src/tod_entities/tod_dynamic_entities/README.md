# tod_dynamic_entities  {#tod_dynamic_entities_docs}

Dynamic Entities describe entities that have dynamic data and are included into the tod_graphics_library as scriptable components. Typically these entities contain a `on_create` and a `on_update` function. 

The `on_create` function is used to generate standard components such as `RenderableElementComponent` and `TransformComponent` as well as setting up the desired shaders. However special setups like `Buffer` or and to interact directly with the rendering api are also possible.

The  `on_update` function is the function called during the render loop.  Typically, the entity is registered in the `StateManager` which determines if the entity should be rendered in the current state of the tod_stack. If it is not registered it is **always** rendered! Typically a function will grab the current data from the associated `SubscribingComponent` and update the meshes or other components accordingly.

If the class is not clear the box will be rendered Grey                                                                                                         	|

| PointCloudRenderer             	| Renders a 3D coloured PointCloud in the scene                                                                                                                                                                                                                                 	|
| PositionController             	| Updates the `base_link` information of the vehicle entity.                                                                                                                                                                                                                    	|
| TrajectoryRenderer             	| Renders the trajectory of the autonomous vehicle                                                                                                                                                                                                                              	|
