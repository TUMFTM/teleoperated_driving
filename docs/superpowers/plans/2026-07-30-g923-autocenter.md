**Goal:** Add and run a safe host-side command that enables 30% fixed autocenter on the Logitech G923.

**Architecture:** A Python standard-library utility resolves the stable G923 `event-joystick` symlink, validates the evdev-reported device name, and writes one `EV_FF/FF_AUTOCENTER` event. Unit tests cover strength validation and binary event encoding; a hardware check confirms the real event write without restarting ToD.

**Tech Stack:** Python 3 standard library, Linux evdev ABI, `unittest`, SSH

- [ ] **Step 3: Implement the minimal utility**

Implement these interfaces:

```python
EV_FF = 0x15
FF_AUTOCENTER = 0x61

def autocenter_value(percent: int) -> int:
    if not 0 <= percent <= 100:
        raise ValueError("strength must be between 0 and 100")
    return int(percent * 65535 / 100)

def encode_autocenter_event(percent: int) -> bytes:
    return struct.pack("@llHHi", 0, 0, EV_FF, FF_AUTOCENTER,
                       autocenter_value(percent))

def is_g923(name: str) -> bool:
    return "Logitech" in name and "G923" in name
```

The CLI accepts an optional integer strength (default `30`), resolves exactly one
`/dev/input/by-id/*G923*-event-joystick`, opens it read/write, obtains its name
with `EVIOCGNAME`, refuses non-G923 devices, writes the encoded event, and prints
the resolved device and applied percentage.
